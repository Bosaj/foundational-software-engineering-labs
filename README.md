# 💻 ENIAD Foundational Computing & Object-Oriented Labs

Core computer science foundations, Object-Oriented Programming (OOP), and Database Engineering developed during **Semestre 5** at **ENIAD** (*École Nationale d'Intelligence Artificielle et du Digital*).

---

## 📚 Curriculum Breakdown
1. **Object-Oriented Programming in Python (`POO Python`)**:
   - Python classes, inheritance, polymorphism, encapsulation, and semester Mini-Project.
2. **Object-Oriented Programming in C++ (`POO C++`)**:
   - Memory management, pointers, constructors/destructors, operator overloading, and standard template library (STL).
3. **Object-Oriented Programming in Java (`POO Java`)**:
   - Abstract classes, interfaces, Java Collections Framework, and unit testing.
4. **Database Engineering (`Ingénierie de Bases de Données`)**:
   - Relational schema normalization (3NF/BCNF), SQL DDL/DML, complex joins, triggers, and stored procedures.
5. **Web Applications Development (`Developpement Applications Web`)**:
   - Semantic HTML5, CSS3 flexbox/grid layout design, media queries, and responsive front-end fundamentals.
